# Vercel環境変数設定ガイド

このドキュメントは、VercelでWebアプリとAdminアプリをデプロイする際に設定する環境変数の一覧です。

## 📋 Web アプリの環境変数

Vercel Dashboard → Web Project → Settings → Environment Variables で以下を設定してください。

### Supabase設定（必須）
```bash
NEXT_PUBLIC_SUPABASE_URL=https://xxxxx.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
SUPABASE_SERVICE_ROLE_KEY=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
```

**取得方法**: Supabase Dashboard → Project Settings → API

---

### AI設定（必須）
```bash
GOOGLE_GENERATIVE_AI_API_KEY=AIzaSy...
```

**取得方法**: [Google AI Studio](https://aistudio.google.com/app/apikey)

---

### Vercel AI Gateway（オプション）
```bash
AI_GATEWAY_API_KEY=your-ai-gateway-key
```

**取得方法**: Vercel Dashboard → AI Gateway設定

---

### Langfuse設定（オプション - LLM監視用）
```bash
LANGFUSE_PUBLIC_KEY=pk-lf-...
LANGFUSE_SECRET_KEY=sk-lf-...
LANGFUSE_BASE_URL=https://cloud.langfuse.com
```

**取得方法**: [Langfuse Dashboard](https://cloud.langfuse.com)

---

### その他の設定
```bash
# キャッシュ無効化用シークレット（ランダムな文字列を設定）
REVALIDATE_SECRET=your-random-secret-key-here

# Adminアプリのurl（デプロイ後に設定）
ADMIN_URL=https://mirai-gikai-admin.vercel.app

# AI Chatの日次コストリミット（USD）
CHAT_DAILY_COST_LIMIT_USD=10

# Basic認証（必要な場合）
BASIC_AUTH_USER=your-username
BASIC_AUTH_PASSWORD=your-password
```

## 📋 Admin アプリの環境変数

Vercel Dashboard → Admin Project → Settings → Environment Variables で以下を設定してください。

### Supabase設定（必須）
```bash
NEXT_PUBLIC_SUPABASE_URL=https://xxxxx.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
SUPABASE_SERVICE_ROLE_KEY=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
```

**取得方法**: Supabase Dashboard → Project Settings → API

---

### Web URL（デプロイ後に設定）
```bash
NEXT_PUBLIC_WEB_URL=https://mirai-gikai.vercel.app
```

---

## 🔄 デプロイフロー

1. **初回デプロイ時**:
   - Supabase関連の環境変数を設定
   - AI関連の環境変数を設定
   - `ADMIN_URL` と `NEXT_PUBLIC_WEB_URL` は仮の値でOK

2. **デプロイ完了後**:
   - 実際のVercel URLを取得
   - `ADMIN_URL` と `NEXT_PUBLIC_WEB_URL` を実際のURLに更新
   - 両アプリを再デプロイ（環境変数変更で自動的に再デプロイされます）

### 環境変数の適用範囲
Vercelでは環境変数を以下の3つの環境に適用できます:
- **Production**: 本番環境（mainブランチ）
- **Preview**: プレビュー環境（PRやその他のブランチ）
- **Development**: ローカル開発環境

通常は全ての環境にチェックを入れることを推奨します。
