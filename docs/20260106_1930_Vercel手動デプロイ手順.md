### 3. デプロイ後の設定

#### 3-1. 実際のURLを確認
- Web アプリのURL（例: `https://mirai-gikai-web-xxx.vercel.app`）
- Admin アプリのURL（例: `https://mirai-gikai-admin-xxx.vercel.app`）

#### 3-2. 環境変数を更新

**Web アプリ**:
1. Vercel Dashboard → Web Project → Settings → Environment Variables
2. `ADMIN_URL` を実際のAdmin URLに更新

**Admin アプリ**:
1. Vercel Dashboard → Admin Project → Settings → Environment Variables
2. `NEXT_PUBLIC_WEB_URL` を実際のWeb URLに更新

#### 3-3. 再デプロイ
環境変数を更新すると自動的に再デプロイされます。

## 🔧 トラブルシューティング

### ビルドエラーが発生した場合
- Root Directoryが正しく設定されているか確認（`web` または `admin`）
- 環境変数が全て設定されているか確認
- Vercelのビルドログを確認

### 環境変数が反映されない
- 環境変数の適用範囲（Production/Preview/Development）を確認
- 環境変数変更後、再デプロイが実行されているか確認

### Supabase接続エラー
- `NEXT_PUBLIC_SUPABASE_URL` と `NEXT_PUBLIC_SUPABASE_ANON_KEY` が正しいか確認
- Supabaseプロジェクトが正常に動作しているか確認
